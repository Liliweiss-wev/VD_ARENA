아레나 1등 역전 계산기

내 점수와 상대 점수를 입력하면 역전에 필요한 회당 점수와 가능 여부를 바로 보여줍니다.

유저

등수닉네임점수

1등으로 입력한 유저(없으면 최고 점수 유저)를 역전 목표로 계산합니다. 점수를 입력하면 점수가 높은 유저가 위로 올라가고 등수가 자동으로 바뀝니다. (⠿ 드래그로 직접 순서를 바꿀 수도 있습니다.)

데이터 백업

데이터는 브라우저 저장소에 자동 저장되지만 캐시·사이트 데이터를 지우면 사라집니다. 중요한 기록은 JSON 파일로 저장해 두고, 삭제 후에는 불러오기로 복구하세요. 내 점수, 유저, 획득점수, 구간표, 시즌 기록이 모두 포함됩니다.

획득 점수별 점수 차 구간

구간 수정

점수 차 = 상대 점수 − 내 점수. 수정을 켜면 min, max를 고칠 수 있고 바로 반영됩니다. 끄면 수정한 값이 기본값으로 저장되고, "기본값으로 되돌리기"는 저장된 기본값으로 복원합니다.

역전 필요 점수

획득점수를 입력하면 그 회차부터 현재 점수와 점수 차, 남은 회당 필요점수가 바로 반영됩니다. 남은 회당 필요점수 = (남은 점수 차 + 1) ÷ 남은 도전 횟수.
